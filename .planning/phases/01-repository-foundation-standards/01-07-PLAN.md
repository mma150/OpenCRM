## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| shadcn command-line tool -> repository | A third-party generator writes source files and may try to add dependencies |
| API error bodies -> page | Server-provided text is rendered to the user |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-SC | Tampering | shadcn init adding or re-versioning packages | high | mitigate | Run the locally installed approved binary (no dlx); diff package.json and lockfile against git; any unapproved package name stops the task with a blocking human verification request |
| T-07-01 | Tampering | rendering server messages | medium | mitigate | Messages render as React text nodes; known codes map to fixed client strings |
| T-07-02 | Tampering | stale or hand-edited API types | low | mitigate | schema.d.ts is generated, lint-ignored, and checked with regenerate plus git diff |
| T-07-03 | Information disclosure | showing request ids to users | low | accept | Request ids are random identifiers with no user data; they help support and are already a response header |
</threat_model>
